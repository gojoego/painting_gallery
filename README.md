A full-stack digital art gallery platform built for showcasing and managing artwork collections.

The application allows artists to display artwork, manage inventory, and eventually support online purchases through integrated payment processing.

## Features

Current:

- Artwork catalog
- Artwork details
- Entity Framework Core data layer
- SQL Server database integration
- CRUD operations for artwork management

Planned:

- Artist admin dashboard
- Image uploads
- Customer checkout
- Stripe payment integration
- Order management
- User authentication
- Deployment pipeline
